# Fitted beard source trial

Selected `grinsegold_full_beard` and `grinsegold_moustache` by **grinsegold** from the official MakeHuman bodyparts06 pack. The original pack, meshes, textures and MHCLO fitting data are retained locally under ignored `raw/`; hashes and license evidence are in provenance.json and license-evidence.html.

The official listing and pack manifest say CC-BY. Legacy autogenerated MHCLO headers say AGPL3. Both notices are preserved; the local personal trial does not resolve exact public redistribution terms. The source notice discrepancy must be resolved before public distribution. Neither source selection nor successful fitting is visual approval.

Elvaerwyn’s scruffy beard was screened out for excessive length. The selected beard is shorter, follows chin/jaw/sideburn regions and has a separate moustache asset; the browser orbit must establish fit, density and likeness.
