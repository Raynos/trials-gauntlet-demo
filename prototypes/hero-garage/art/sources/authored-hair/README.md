# Authored hair source

Cortu **Short messy hair**, CC0 per the official [hair01 pack listing](https://static.makehumancommunity.org/assets/assetpacks/hair01.html). Exact archive and extracted-file hashes are in provenance.json; source license evidence is retained. OBJ, MHCLO fitting weights, diffuse coverage texture and object-space normal are local under raw/hair01/hair/cortu_short_messy_hair. Do not treat its object-space normal as a glTF tangent normal.

The parent screened source thumbnails for length and texture construction. This is source selection, not acceptance of the hero; only the fitted browser orbit can establish that. Hair03 long curly assets were screened out and are unused. The selected source needs a dark-brown color adaptation and may still miss the target curl silhouette. Raw downloads are ignored; any adapted runtime asset must retain source and change records.
