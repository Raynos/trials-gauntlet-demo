# Daniel Bystedt authored curly groom

Acquired from the official public Blender demo download, 28,612,482 bytes. SHA256 and exact source in provenance.json. Official demo page and embedded Hair demo file info agree on Daniel Bystedt, CC BY-SA; neither specifies a version. Retain attribution and share-alike for derivative groom. Raw original remains local and unchanged.

Blender 5.2.1 imports it successfully. The actual curly object has 303 authored guide curves / 3,636 points, a matching 876-vertex/796-face growth mesh, and editable Surface Deform + Curly hair Geometry Nodes. Evaluating the author's unchanged graph produces 22,418 curves / 515,614 points. It contains actual curled strands and guide clumping, not one opaque hair atlas. The original style has longer lower sides and larger curl volume than the target, so fitting/shortening and runtime conversion still require review. No ready-made glTF or runtime atlas exists; dense curves must be explicitly converted/baked.

Selected replacement trial is bounded to this groom. Hair02 previews examined (Maxwell, Grump, Short Daisy, Micky Afro and Inverted Curly Bob) were broad styled meshes/long bobs and were not downloaded as alternatives. Current A3 MPFB asset was left unchanged during intake.
